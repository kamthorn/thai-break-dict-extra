# thai-break-dict-extra

คลังคำศัพท์พิเศษ (Extra / Custom Thai Dictionary) สำหรับเพิ่มความแม่นยำในการตัดคำภาษาไทย (Thai Word Tokenization / Segmentation) ให้แก่ระบบตัดคำ เช่น **[thai-break](https://github.com/kamthorn/thai-break)**, **thai-break-service**, หรือ Tokenizer อื่น ๆ

โปรเจกต์นี้เน้นรวบรวมคำศัพท์ที่มัก **ไม่ปรากฏในพจนานุกรมมาตรฐานทั่วไป** หรือคำที่มักจะถูกตัดเป็นชิ้นเล็กชิ้นน้อยผิดความหมาย เช่น ชื่อเฉพาะ, คำทับศัพท์ภาษาต่างประเทศ, คำสแลง, คำเฉพาะกลุ่ม และคำที่มักสะกดผิดในชีวิตประจำวัน

## 📁 โครงสร้างหมวดหมู่คำศัพท์ (`data/`)

```text
data/
├── proper-names/             # ชื่อเฉพาะ (Proper Names / Named Entities)
│   ├── provinces.txt         # รายชื่อ 77 จังหวัด และชื่อเรียกยอดนิยม (เช่น กรุงเทพฯ, อยุธยา, โคราช)
│   ├── districts.txt         # อำเภอ, เขต, แขวง, ตำบล, เมืองท่องเที่ยวสำคัญ
│   ├── countries.txt         # ชื่อประเทศ, ดินแดน และเมืองสำคัญทั่วโลก (ภาษาไทย)
│   ├── organizations.txt     # หน่วยงานราชการ, กระทรวง, กรม, องค์กรสากล, ธนาคาร
│   ├── brands.txt            # แบรนด์สินค้า, บริษัท, แพลตฟอร์มโซเชียล, ห้างสรรพสินค้า
│   └── persons.txt           # ชื่อบุคคลสำคัญ, บุคคลสาธารณะ
│
├── loanwords/                # คำทับศัพท์ / คำยืมภาษาต่างประเทศ
│   ├── tech.txt              # ศัพท์คอมพิวเตอร์, เทคโนโลยี, ซอฟต์แวร์, AI
│   ├── food.txt              # อาหาร, ขนม, เครื่องดื่ม, ชา, กาแฟ
│   └── general.txt           # คำทับศัพท์ทั่วไป, กิจกรรม, ไลฟ์สไตล์, แฟชั่น
│
├── misspellings/             # คำที่มักสะกดผิดบ่อย (Common Misspellings)
│   └── common.txt            # คำเขียนผิดที่พบบ่อย (เช่น กะเพรา/กระเพรา, อนุญาต/อนุญาติ)
│
├── slang/                    # คำสแลง / ภาษาปาก / ศัพท์อินเทอร์เน็ต
│   └── internet.txt          # คำฮิตติดเทรนด์โซเชียลมีเดีย, ศัพท์วัยรุ่น
│
└── domains/                  # ศัพท์เฉพาะทางตามสาขาวิชาชีพ
    ├── medical.txt           # การแพทย์, สาธารณสุข, ชื่อโรค, ยา, อาการ
    ├── finance.txt           # การเงิน, หุ้น, คริปโทเคอร์เรนซี, บัญชี, ภาษี
    └── legal.txt             # กฎหมาย, การดำเนินคดี, นิติกรรม, ศาล
```

## 🛠️ เครื่องมือและสคริปต์ (`scripts/`)

ทุกสคริปต์เขียนด้วย **Python 3 Standard Library** โดยไม่ต้องติดตั้งแพ็กเกจภายนอกเพิ่มเติม

### 1. การจัดรูปแบบไฟล์อัตโนมัติ (`format.py`)
ทำความสะอาดข้อมูล ตัดช่องว่าง/อักขระล่องหน (Zero-width space, BOM), กรองคำซ้ำในไฟล์ และเรียงลำดับ (Sort) ให้อัตโนมัติ:
```bash
python3 scripts/format.py
```

### 2. การตรวจสอบความถูกต้อง (`validate.py`)
ตรวจสอบว่าทุกไฟล์เป็นไปตามมาตรฐาน (เหมาะสำหรับใช้ใน CI / Pre-commit hook):
- ต้องเข้ารหัสแบบ **UTF-8 (No BOM)**
- ใช้การขึ้นบรรทัดใหม่แบบ Unix (`\n` เท่านั้น ไม่มี `\r`)
- ไม่มีบรรทัดว่างและไม่มีช่องว่างหน้า/หลังคำ
- คำในแต่ละไฟล์ต้องจัดเรียงลำดับอย่างถูกต้อง
- ตรวจสอบคำที่ซ้ำซ้อนข้ามหมวดหมู่
```bash
python3 scripts/validate.py
```

### 3. การ Build รวมไฟล์คำศัพท์ (`build.py`)
รวบรวมคำศัพท์จากทุกหมวดหมู่ ตัดคำซ้ำ และส่งออกเป็นไฟล์เดียวที่พร้อมนำไปใช้งาน:
```bash
# รวมคำศัพท์ทั้งหมดเป็น dist/words-extra.txt
python3 scripts/build.py

# รวมและเปรียบเทียบกับพจนานุกรมหลัก พร้อมบันทึกไฟล์ผลลัพธ์รวม
python3 scripts/build.py \
  --base-dict ../thai-break-service/data/words.txt \
  --merged-output dist/words-merged.txt
```

## 🚀 การนำไปใช้งานร่วมกับ `thai-break-service`

### วิธีที่ 1: ชี้ path ผ่าน Environment Variable
กำหนด path ไปยังไฟล์คำศัพท์ที่ build แล้ว:
```bash
export DICT_PATH="/path/to/thai-break-dict-extra/dist/words-merged.txt"
./thai-break-service
```

### วิธีที่ 2: แทนที่ไฟล์เดิมใน thai-break-service
```bash
cp dist/words-merged.txt ../thai-break-service/data/words.txt
```

## 🤝 ข้อแนะนำในการร่วมเพิ่มคำศัพท์ (Contribution Guidelines)

1. เลือกหมวดหมู่ไฟล์ในโฟลเดอร์ `data/` ให้ตรงกับประเภทของคำศัพท์
2. ใส่คำศัพท์ **1 คำ ต่อ 1 บรรทัด**
3. คำศัพท์ไม่ควรมีวรรคตอนหรือช่องว่างหน้า/หลัง
4. เมื่อเพิ่มคำศัพท์แล้ว ให้รันคำสั่ง:
   ```bash
   python3 scripts/format.py
   python3 scripts/validate.py
   ```
5. ตรวจสอบให้แน่ใจว่าการทดสอบผ่านฉลุยก่อนส่ง Pull Request
